Guia de Criação de Modelos

Aprenda a configurar seus arquivos Word (.docx) para funcionarem com o DunaDoc.

1. O Básico (Variáveis) 2. Tipos de Campos 3. Lógica Condicional (Se/Então) 4. Formatação e Estilo 5. Imagens e Assinaturas

1. O Básico: Criando Variáveis

Para criar um espaço que será preenchido automaticamente, você deve usar chaves duplas no seu arquivo Word.

Sintaxe: {% verbatim %}{{ nome_da_variavel }}{% endverbatim %}
Não faça assim:
  • { nome } (Falta uma chave)
  • (( nome )) (Parênteses não funcionam)
  • {% verbatim %}{{ Nome do Cliente }}{% endverbatim %} (Evite espaços no nome da tag)
Recomendado:
  • {% verbatim %}{{ nome_cliente }}{% endverbatim %} (Use underline)
  • {% verbatim %}{{ cpf }}{% endverbatim %} (Simples e direto)
  • {% verbatim %}{{ data_assinatura }}{% endverbatim %}

2. Tipos de Campos Disponíveis

Ao configurar o modelo no sistema, você poderá escolher o "Tipo de Resposta". Isso muda como o formulário aparece para o advogado.

Tipo no Sistema Quando usar? Como configurar no Word
Texto Curto Nomes, Cidades, Profissões. {% verbatim %}{{ profissao }}{% endverbatim %}
Texto Longo Fatos, descrições detalhadas, parágrafos inteiros. {% verbatim %}{{ dos_fatos }}{% endverbatim %}
Data Datas de assinatura, audiência, ajuizamento. {% verbatim %}{{ data_audiencia }}{% endverbatim %} (O sistema formatará para DD/MM/AAAA)
CPF/CNPJ Documentos. O sistema aplica máscara automática. {% verbatim %}{{ cpf_autor }}{% endverbatim %}
Moeda (R$) Valores da causa, indenizações. {% verbatim %}{{ valor_causa }}{% endverbatim %}
Sim/Não (Checkbox) Para ativar/desativar parágrafos (ver Lógica abaixo). {% verbatim %}{{ pede_justica_gratuita }}{% endverbatim %}

3. Lógica Condicional

Você pode fazer parágrafos aparecerem ou sumirem dependendo de uma resposta Sim/Não.

Exemplo Prático: Justiça Gratuita

No Word, escreva assim:

{% verbatim %} {% if justiça_gratuita %} Requer, preliminarmente, os benefícios da Justiça Gratuita, por ser pobre na forma da lei. {% endif %} {% endverbatim %}

No sistema, configure a variável justiça_gratuita como tipo Checkbox (Sim/Não).

Se o advogado marcar "Sim", o texto aparece. Se não marcar, o texto é removido do documento final.

Lógica de Alternativa (Se... Senão)
{% verbatim %} {% if eh_empresa %} Inscrito no CNPJ sob o nº {{ cnpj }} {% else %} Inscrito no CPF sob o nº {{ cpf }} {% endif %} {% endverbatim %}

4. Formatação e Estilo

O sistema respeita a formatação que você aplicar na tag dentro do Word.

Se você colocar negrito na tag:

{% verbatim %}{{ nome }}{% endverbatim %}

O resultado final sairá em negrito.

Se você colocar cor vermelha:

{% verbatim %}{{ prazo }}{% endverbatim %}

O resultado final sairá vermelho.

5. Imagens e Assinaturas

Para inserir prints, fotos de documentos ou assinaturas dinâmicas.

  1. Coloque uma tag normal no Word: {% verbatim %}{{ print_whatsapp }}{% endverbatim %}
  2. No sistema, configure essa variável com o tipo Imagem/Print.
  3. O sistema irá redimensionar automaticamente a imagem enviada para caber na largura da página (16cm).
