Guia de criação de modelos

Manual completo de sintaxe Word e configuração do sistema.

1. O básico 2. Tipos de campos 3. Lógica (IF/ELSE) 4. Dependências 5. Formatação e filtros 6. Imagens

1. O básico: criando variáveis

Para criar um campo preenchível no Word, use chaves duplas.

Certo:
{% verbatim %}{{ nome_cliente }}{% endverbatim %}
{% verbatim %}{{ data_hoje }}{% endverbatim %}
{% verbatim %}{{ valor_causa }}{% endverbatim %}
Errado:
{ nome } (falta chave)
{% verbatim %}{{ Nome do Cliente }}{% endverbatim %} (tem espaços)
{% verbatim %}{{ data-hoje }}{% endverbatim %} (use underline)

2. Tipos de campos no sistema

Ao subir o arquivo, você deve configurar o tipo de cada variável:

TipoUso recomendado
Texto curtoNomes, cidades, profissões, RG.
Texto longoParágrafos inteiros, descrições de fatos.
DataO sistema exibe um calendário e formata como DD/MM/AAAA.
Moeda (R$)Valores monetários.
CPF/CNPJAplica a máscara de pontos e traço automaticamente.
CheckboxFundamental para lógica condicional (Sim/Não).
ImagemPara prints e assinaturas.
Lista suspensaPara forçar a escolha entre opções fixas (ex: Deferido / Indeferido).
Como configurar uma lista suspensa?
1. No Word, crie a variável normalmente: {% verbatim %}{{ resultado_liminar }}{% endverbatim %}.
2. No sistema (tela de configuração), selecione o tipo Lista suspensa.
3. Digite as opções separadas por vírgula (ex: Deferido, Indeferido, Aguardando).

3. Lógica simples e avançada (IF)

Use para mostrar ou ocultar blocos de texto inteiros.

1. Sim ou não (Checkbox)
// Se "pedir_gratuidade" estiver marcado:
{% verbatim %}{% if pedir_gratuidade %}
    Requer os benefícios da Justiça Gratuita, por ser pobre na forma da lei.
{% endif %}{% endverbatim %}
2. Comparação de texto (Dropdown)
// Exemplo: variável "estado_civil" com opções "Casado, Solteiro"

{% verbatim %}{% if estado_civil == "Casado" %}
    casado, residente e domiciliado com sua esposa...
{% elif estado_civil == "Solteiro" %}
    solteiro, residente e domiciliado...
{% else %}
    estado civil declarado como {{ estado_civil }}...
{% endif %}{% endverbatim %}
Atenção: o texto entre aspas deve ser idêntico (letras maiúsculas e acentos) ao cadastrado nas opções do sistema.

4. Aninhamento e dependências

Você pode criar formulários inteligentes onde campos só aparecem se uma opção anterior for marcada.

Passo 1: no Word (a Matrioska)

Coloque um if dentro de outro. Exemplo de preliminares:

{% verbatim %}{% if tem_preliminares %}
  II. DAS PRELIMINARES

  {% if pede_incompetencia %}
    DA INCOMPETÊNCIA DO JUÍZO
    O juízo é incompetente em razão do lugar...
  {% endif %}

  {% if pede_ilegitimidade %}
    DA ILEGITIMIDADE PASSIVA
    A parte ré não possui relação jurídica...
  {% endif %}
{% endif %}{% endverbatim %}

Passo 2: no sistema (configuração)

Para que o formulário entenda essa lógica e esconda os campos filhos:

  1. Vá em Configurar modelo.
  2. Defina tem_preliminares como Checkbox.
  3. Defina pede_incompetencia como Checkbox (ou outro tipo).
  4. Na coluna "Condição" da variável pede_incompetencia, selecione: Se "tem_preliminares" for SIM.
Resultado: no formulário de preenchimento, os campos filhos ficarão ocultos até que você marque "Tem preliminares".

5. Formatação e filtros

Você pode alterar o texto diretamente na tag usando o pipe |.

SintaxeFunçãoExemplo
{% verbatim %}{{ nome|upper }}{% endverbatim %}Tudo maiúsculoJOÃO SILVA
{% verbatim %}{{ cidade|title }}{% endverbatim %}Primeira letra maiúsculaRio De Janeiro
{% verbatim %}{{ estado|lower }}{% endverbatim %}Tudo minúsculorio grande do norte
{% verbatim %}{{ valor|default:"0,00" }}{% endverbatim %}Valor padrão se vazio0,00

6. Imagens e prints

Para inserir prints de WhatsApp, comprovantes ou assinaturas.

  • Use uma tag normal: {% verbatim %}{{ print_conversa }}{% endverbatim %}
  • No sistema, escolha o tipo Imagem/Print.
  • O sistema redimensionará automaticamente a imagem para caber na página (máximo 16cm de largura), mantendo a proporção.
