Guia de Criação de Modelos

Manual completo de sintaxe Word e configuração do sistema.

1. O Básico 2. Tipos de Campos 3. Lógica Simples 4. Dependências (Novo 🚀) 5. Formatação e Filtros 6. Imagens

1. O Básico: Criando Variáveis

Para criar um campo preenchível no Word, use chaves duplas.

Certo:
{% verbatim %}{{ nome_cliente }}{% endverbatim %}
{% verbatim %}{{ data_hoje }}{% endverbatim %}
{% verbatim %}{{ valor_causa }}{% endverbatim %}
Errado:
{ nome } (Falta chave)
{% verbatim %}{{ Nome do Cliente }}{% endverbatim %} (Tem espaços)
{% verbatim %}{{ data-hoje }}{% endverbatim %} (Use underline _)

2. Tipos de Campos no Sistema

Ao subir o arquivo, você deve configurar o tipo de cada variável:

Tipo Uso Recomendado
Texto Curto Nomes, Cidades, Profissões, RG.
Texto Longo Parágrafos inteiros, descrições de fatos.
Data O sistema exibe um calendário e formata como DD/MM/AAAA.
Moeda (R$) Valores monetários.
CPF/CNPJ Aplica a máscara de pontos e traço automaticamente.
Checkbox Fundamental para Lógica Condicional (Sim/Não).
Imagem Para prints e assinaturas.

3. Lógica Condicional (Se/Então)

Use para mostrar ou ocultar blocos de texto inteiros.

No Word:

{% verbatim %} {% if pedir_gratuidade %} Requer os benefícios da Justiça Gratuita, por ser pobre na forma da lei. {% endif %} {% endverbatim %}
Dica: Configure a variável pedir_gratuidade como Checkbox no sistema.

4. Aninhamento e Dependências 🚀

Agora você pode criar formulários inteligentes onde campos só aparecem se uma opção anterior for marcada.

Passo 1: No Word (A Matrioska)

Coloque um if dentro de outro. Exemplo de Preliminares:

{% verbatim %} {% if tem_preliminares %} II. DAS PRELIMINARES {% if pede_incompetencia %} DA INCOMPETÊNCIA DO JUÍZO O juízo é incompetente em razão do lugar... {% endif %} {% if pede_ilegitimidade %} DA ILEGITIMIDADE PASSIVA A parte ré não possui relação jurídica... {% endif %} {% endif %} {% endverbatim %}
Passo 2: No Sistema (Configuração)

Para que o formulário entenda essa lógica e esconda os campos filhos:

  1. Vá em Configurar Modelo.
  2. Defina tem_preliminares como Checkbox.
  3. Defina pede_incompetencia como Checkbox (ou outro tipo).
  4. Na coluna "Condição (Aparece se...)" da variável pede_incompetencia, selecione: Se "tem_preliminares" for SIM.
Resultado: No formulário de preenchimento, os campos filhos ficarão ocultos até que você marque "Tem Preliminares".

5. Formatação e Filtros

Você pode alterar o texto diretamente na tag usando o pipe |.

Sintaxe Função Exemplo
{% verbatim %}{{ nome|upper }}{% endverbatim %} Tudo Maiúsculo JOÃO SILVA
{% verbatim %}{{ cidade|title }}{% endverbatim %} Primeira Letra Maiúscula Rio De Janeiro
{% verbatim %}{{ estado|lower }}{% endverbatim %} Tudo minúsculo rio grande do norte
{% verbatim %}{{ valor|default:"0,00" }}{% endverbatim %} Valor padrão se vazio 0,00

6. Imagens e Prints

Para inserir prints de WhatsApp, comprovantes ou assinaturas.

  • Use uma tag normal: {% verbatim %}{{ print_conversa }}{% endverbatim %}
  • No sistema, escolha o tipo Imagem/Print.
  • O sistema redimensionará automaticamente a imagem para caber na página (máximo 16cm de largura), mantendo a proporção.
